# Kanban-Task-Board

A simple and interactive Kanban-style task management app built with **HTML**, **CSS**, and **JavaScript**.  
You can create tasks, drag them between columns, delete them, and all data is saved automatically using **localStorage**.

---

## 🚀 Features

### ✔ Add New Tasks  
Click the **"Add New Task"** button to quickly create a new task.  
All new tasks automatically appear in the **To-Do** column.

### ✔ Drag & Drop  
You can drag tasks between:  
- 🟦 **To-Do**  
- 🟨 **In Progress**  
- 🟩 **Done**  

The changes are saved instantly.

### ✔ Persistent Storage  
All tasks are stored in **localStorage**, so your data remains intact even if you close or refresh the browser.

### ✔ Delete Tasks  
Each task has a delete button so you can remove tasks easily.

---

## 🛠 Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **localStorage API**
